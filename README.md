## 🎯 Project Goal

The main objective of this project was:

- To completely redesign an outdated staircase business website
- To build a **modern, luxury UI/UX experience**
- To improve user engagement and visual hierarchy
- To create a **conversion-focused landing experience**
- To showcase strong frontend development and design skills

---

## 🧠 UI/UX Improvements

- Fully modern and minimal design system
- Luxury-inspired visual direction
- Improved typography & spacing system
- Better user flow & navigation structure
- Smooth animations & micro-interactions
- Mobile-first responsive design
- Strong CTA placement for conversions

---

## ⚙️ Tech Stack

- **Next.js** – React Framework
- **Tailwind CSS** – Styling
- **Framer Motion** – Animations
- **JavaScript (ES6+)**
- **Responsive Design Principles**

- 📱 Fully responsive (Mobile, Tablet, Desktop)
